# Optional persistent subagent example
+
+```yaml
+---
+name: migration-planner
+description: Plan reviewed PostgreSQL migrations and retain verified project observations.
+tools: Read, Glob, Grep
+memory: project
+---
+```
+
+Persistent memory can enable memory writing tools. Do not describe this configuration as a strictly read-only reviewer. The baseline reviewers deliberately omit memory. Review retained facts and promote binding rules into versioned project instructions.
+
+Paměť subagenta může zpřístupnit zápis paměťových souborů. Takovou konfiguraci neoznačujte za striktně čtecího reviewera. Základní revieweři proto memory neuvádějí. Ověřené závazné poznatky přenášejte do verzovaných týmových pravidel.
+
